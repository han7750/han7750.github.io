# road 현관 사이트

`https://han7750.github.io/` — 진짜 사이트(`/gil/`) 로 안내하는 현관 페이지입니다.

## 왜 이 저장소가 따로 있나

네이버·구글 검색 등록은 **주소 맨 앞** 단위로만 받습니다.
사이트는 `han7750.github.io/gil/` 이라는 **하위 폴더**에 있어서 등록할 수 없었고,
맨 앞 주소는 아무것도 없는 404 였습니다.

도메인을 사지 않고 해결하려고, 맨 앞에 놓을 현관을 무료로 하나 만들었습니다.

| 주소 | 저장소 | 무엇 |
|---|---|---|
| `han7750.github.io/` | **이 저장소** | 현관. 누르면 `/gil/` 로 감 |
| `han7750.github.io/gil/` | `han7750/gil` | 진짜 사이트 |

## ⚠ 절대 지우면 안 되는 파일

```
naver82d0d6e1daa5b9e3cac24eefd09a194b.html
```

**네이버에 "이 사이트 주인이 맞다"고 증명하는 쪽지입니다.**
네이버는 한 번 확인하고 끝내는 게 아니라 **가끔씩 다시 보러 옵니다.**
이 파일을 지우면 소유확인이 풀리고, 검색 등록도 같이 풀립니다.

2026-08-14에 소유확인을 통과했습니다.

## 파일 설명

| 파일 | 무엇 |
|---|---|
| `index.html` | 현관 화면. 색과 모양은 `<style>` 맨 위 `:root` 한 곳에만 |
| `robots.txt` | 검색 로봇 안내문. **맨 앞 주소에만** 놓을 수 있어서 여기 있음 |
| `sitemap.xml` | 주소 목록표 |
| `naver...html` | 네이버 소유확인 쪽지 (위 경고 참고) |
| `.nojekyll` | 깃허브가 파일을 함부로 가공하지 않게 막음 |

## 구글에도 등록하려면

`index.html` 안에 `google-site-verification` 자리를 만들어 뒀습니다.
구글 서치 콘솔(https://search.google.com/search-console)에서 코드를 받아
큰따옴표 사이만 갈아 끼우면 됩니다.
